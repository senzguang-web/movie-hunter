# 电影猎手 · Movie Hunter

这是可直接托管在 GitHub Pages 的静态网站发布包，支持域名根目录及项目子目录（例如 /movie-hunter/）。将本目录作为站点根目录发布即可，无需 Node.js 服务、依赖安装或 API 密钥。

## 使用体验

首页为星尘影院：中文 / English · 心情输入 → 观影感受 → 电影类型多选 → 片长 → 国家／地区多选 → 主推荐与候选切换 → 确认今晚的电影。

文字与海报沿连续曲线聚合、消散；下方青色点云分为三层景深，随缓慢波形起伏。动效参考 KIN Movie 的粒子菜单（https://www.awwwards.com/inspiration/interactive-particles-menu），以原创 Canvas 实现，不依赖原站代码或素材。正式页面隐藏动效实验导航，支持暂停动态和系统减少动态设置。

输入的文字带有轻柔的星尘聚合效果，保留原生光标与中文输入。右上角「海岸声」可开启海浪与远处海鸥的实地录音：默认关闭，6 秒淡入，关闭时淡出，切换问答持续播放，离开标签页自动暂停。录音来源和许可见 assets/audio/sources.json。

每轮根据本次输入和回答挑选最多 7 部电影。首次推荐在相近心境匹配度下优先豆瓣或 IMDb 有来源的 8 分及以上作品；各平台评分分开展示，不生成综合评分。主动点击「换一组故事」时，在契合观影意图的候选中优先选择尚未推荐的电影，再轮换较早出现的作品，同一层级仍保留匹配度与高分优先。符合此刻心境的旧片可以再次出现。页面显示实际换入数量及剩余未推荐数量；没有更多合适影片时明确提示，不通过放宽类型、国家或片长条件凑数。

类型多选匹配其中一种即可，国家／地区多选匹配其中一个即可，并同时严格遵守片长上限。支持桌面与手机布局、键盘操作。星尘影院的问答、语言和本轮选择只保留在当前页面会话，刷新后重置，不上传心情原文。

旧版仍可通过 [classic.html](classic.html) 访问，其原有收藏与偏好仍保留在同一浏览器的本地存储中。新版不会覆盖这些数据。

## 当前范围

- 精选片库共 32 部电影，涉及 20 个制片国家／地区；不是全网电影搜索。
- 情绪识别使用本地中英文关键词及编辑标签，不调用语言模型；复杂表达可能识别不完整。
- 24 部影片包含有来源的评分快照。页面标注演示状态、核验日期并提供原始来源；不是实时分数，缺失评分不会编造。
- 静态版直接读取随站点提供的快照，不调用服务器评分接口，也不包含后台或自动更新服务。更新片库或评分需重新导出发布。
- 本站提供选片建议和影片资料，不提供电影播放、下载或流媒体订阅。
- 字体可从 Google Fonts 加载；字体服务不可用时使用系统字体，不影响选片功能。

## 发布包边界

本包仅包含白名单中的网页、脚本、样式、在用海报和来源记录。不包含服务端程序、环境变量、API 密钥、微信项目配置、私人配置或本地浏览记录。deployment.js 指定静态快照模式，.nojekyll 让 GitHub Pages 直接发布静态文件。

资源使用站点相对路径；请通过站点的目录入口（以 / 结尾）访问。可用任意静态 HTTP 服务预览。源项目通过 npm run export:pages 重新生成此包，也可在命令后提供目标目录。
